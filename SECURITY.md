# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use the
["Report a vulnerability"](https://github.com/mohamedtaqysalmi/fastapi-prod-checklist/security/advisories/new)
form on the Security tab of this repository. The report stays private between you and me.

I maintain this project alone, so a reply can take a few days. I will confirm the report,
tell you whether I can reproduce it, and say how I plan to fix it.

## Supported versions

The project is an early scaffold with no releases yet. Only the latest commit on `main` is supported.
