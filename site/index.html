How it works

Honest limits

  • Rate limiting is in-process; multi-worker needs a shared store.
  • 500 responses currently miss CORS headers (Starlette layering).
  • Redaction is key-name based; free-text secrets can still leak into logs.
  • OpenAPI UI is off because CSP is strict on purpose.

How I built it

  • Readiness tests assert HTTP behaviour, not private function names.
  • Dockerfile USER is asserted by reading the file in CI.
  • Sentry only loads when APP_SENTRY_DSN is set.
  • Alembic ships with a real upgrade head against SQLite in tests.

Roadmap

Tracked as GitHub issues under milestone v0.2.0. Next up: shared-store rate limiting, CORS on 500s, and richer readiness probes.
